# Nitesh Kushwaha — Developer Portfolio

Personal developer portfolio website built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**.

## 🚀 Key Highlights & Stack

- **Unified Engineering Positioning:** Frontend Engineer specializing in Angular, React & Next.js — with full-stack MEAN capability.
- **SSR Performance Boost:** Demonstrates a **167% Lighthouse score gain** (30 → 80+).
- **Backend & Full-Stack Capabilities:** Showcases Node.js, Express.js, MongoDB, Mongoose, Aggregation Pipeline, and RESTful APIs.
- **Interactive Technical Arsenal:** Search bar & category filtering for skills.
- **Dual Resume Selector:** Targeted downloads for Frontend roles vs. Full-Stack MEAN roles.
- **Terminal Motif & Audio Cues:** `$ whoami` terminal visual card aligned with LinkedIn branding, plus sound effect feedback & mute control.

## 🛠️ Getting Started

First, install dependencies and run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
